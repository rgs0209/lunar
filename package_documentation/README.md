# PACKAGE DOCUMENTATION

This folder contains provenance and validation material for the complete CV
intern package. The interns should begin with their own project folder and use
this folder only when they need to verify the study-area definition or data
lineage.

## Contents

- `manifests/roi_manifest.csv`: exact Area A/B windows and map bounds.
- `manifests/layer_inventory.csv`: source, resolution, status, and limitation
  for every supplied raster layer.
- `manifests/provenance.json`: package-generation rules and source locations.
- `manifests/file_inventory.csv`: file sizes and SHA-256 checksums.
- `manifests/VALIDATION_REPORT.md`: final structure and data validation.
- `figures/consensus_areas_overview.png`: location of Areas A and B.
- `INTERN_OUTPUTS_NAVIGATOR.md`: index of the original Intern 2-4 submissions.
